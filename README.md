# Roguelike

This game is not finished!

It's a simple pixel art game. Currently there is still only this one level.

# Movement

WASD and the arrow buttons should both work.

Use X for attack

# Installation

You can play the game without downloading it. I uploaded it on itch.io: https://ciferwolf.itch.io/roguelike

There are some issues with the size of the window, but 99% of the game is visible ;)

# Process of making the game

The game was made with Unity. The focus was to learn the basics of Game Development. The important features in the game were the creation of a map and the player interactions with the map, enemies and the finish (A gold coin).

# AI

I used Claude for figuring out some issues I've had with the engine. The game was made by me alone. There were some issues eninge-wise, so I had to use AI to figure them out

# Future of this project

I will continue working on this game, due to there being a lot of unfinished details. In addition to that I want to add more levels and improve on the UI a lot
